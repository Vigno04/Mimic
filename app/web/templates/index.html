Crucial Stage 2 of 5

                  
Enable Privileged Gateway Intents

                

                

                  ⚠️ Why this matters: Without Message Content Intent, Discord prevents bots from reading any message text! The bot will be online but won't respond to anything.
                

                
                

                  

                    1
                    
In Discord Developer Portal, stay on the "Bot" tab.

                  

                  

                    2
                    
Scroll down to the "Privileged Gateway Intents" section.

                  

                  

                    3
                    
Toggle ON the following 3 switches:

                  

                


                

                  

                    

                      REQUIRED
                      MESSAGE CONTENT INTENT
                    

                    
Allows the bot to read chat messages and process keyword/command triggers.

                  

                  

                    

                      RECOMMENDED
                      SERVER MEMBERS INTENT
                    

                    
Allows tracking user names, IDs, mentions, and long-term user memories.

                  

                  

                    

                      OPTIONAL
                      PRESENCE INTENT
                    

                    
Allows viewing member activity and online status.

                  

                


                

                  4
                  
Click the green "Save Changes" button at the bottom of the Discord page.

📘 Discord Bot Setup & Troubleshooting Guide

        
      

      

        

          
🚀 5-Step Discord Bot Deployment Checklist

          
    
            
  1. Create App: Go to Discord Developer Portal ↗ ➔ Click New Application.
    2. 
            
  2. Get Token: In the Bot tab, click Reset Token and paste it into this platform.
    3. 
            
  3. Enable Gateway Intents: In the Bot tab, scroll down to Privileged Gateway Intents and toggle ON Message Content Intent and Server Members Intent, then click Save Changes.
    4. 
            
  4. Invite to Server: In OAuth2 ➔ URL Generator, select scopes bot & applications.commands, permissions Send Messages, View Channels, Read Message History, and open the URL in your browser.
    5. 
            
  5. Set AI Model & Triggers: Configure at least one AI Endpoint in this platform, set your triggers (e.g. /ask, @Mention, keyword), and click Start.
    6. 
          

        


        

          
🔍 Common Issues & Solutions

          

            

              • Bot shows "online" but ignores all messages / commands:

              Make sure Message Content Intent is toggled ON in Discord Developer Portal under Bot ➔ Privileged Gateway Intents. Without it, Discord silently strips message text.
            

            

              • Bot cannot read or reply in private channels:

              Check server role permissions. The bot role must have "View Channel" and "Send Messages" permissions in that specific channel.
            

            

              • Error: 401 Unauthorized / Token Invalid:

              Regenerate the token in Discord Developer Portal (Bot ➔ Reset Token) and update it in the bot editor.
